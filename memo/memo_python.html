GDAL

La documentation est ici. Commande très utile : gdalinfo

Ajouter -overwrite pour écraser les fichiers existants, -q si on ne veut pas que les messages automatiques de GDAL s'affichent. QGIS sort les commandes GDAL dans chaque tâche réalisée. Lat/lon classique : EPSG:4326.

Découper un raster suivant un shapefile (.shp ou .gpkg)/une emprise: 

gdalwarp -cutline shapefile.shp -crop_to_cutline -tr 10 10 -dstnodata nan -of GTiff file.tif the_new_file.tif
gdalwarp -te west south east north file.tif the_new_file.tif

Pour les MNT : calculer les orientations et les pentes à partir de l'altitude 

gdaldem aspect file_MNT_elevation.tif file_aspect_out.tif -of GTiff -b 1 -s 1.0
gdaldem slope file_MNT_elevation.tif file_slope_out.tif -of GTiff -b 1 -s 1.0

Modifier la résolution spatiale 

gdalwarp -tr 10 10 -tap -r near -t_srs EPSG:32631 infile.tif outfile.tif

Calculer une carte binaire : 

gdal_calc.py -A file.tif --outfile=binary_file.tif --calc="(A==100)*1" --type=Byte

Aligner la grille d'un .tif sur un autre fichier: 

#!/bin/bash
read ULX ULY LRX LRY <<< $(gdalinfo "$FILE_REF" | awk '/Upper Left/ {gsub(/[(),]/,""); x1=$3; y1=$4} /Lower Right/ {gsub(/[(),]/,""); x2=$3; y2=$4} END {print x1, y2, x2, y1}')
echo "Emprise extraite : $ULX $LRY $LRX $ULY"
EPSG_CODE=$(gdalsrsinfo -o epsg "$FILE_REF" | grep -oE 'EPSG:[0-9]+')
echo "Projection détectée : $FILE_REF"
gdalwarp -overwrite -tr $RES $RES -tap -r bilinear -t_srs "$EPSG_CODE" -te "$ULX" "$ULY" "$LRX" "$LRY" -wo "INIT_DEST=NO_DATA" "$FILE_IN" "$FILE_OUT"
# Vérifier la taille des pixels
gdalinfo "$FILE_OUT" | grep "Pixel Size"
